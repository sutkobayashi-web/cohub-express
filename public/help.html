❓ CoWell ヘルプ

← ホーム
CoWell (Communication & Wellness) はスタンダード運輸グループの社内コミュニケーション・健康推進プラットフォームです。 気軽に投稿・反応・相談しながら、日々の体調と職場の声を可視化していきます。
📅 毎日使う 🩺 健康・食事 💬 コミュニケーション 🎯 サークル活動 🚛 LogiHub・現場系 🩺 推進メンバー ❓ よくある質問

📅 毎日の業務に使う

⏰

出退勤打刻

「出勤」「退勤」の大ボタンを押すだけ。PC起動時刻と打刻ラグが15分以上だと⚠が表示され、サービス残業の見える化につながります。

PC起動通知: 須貝さん経由で1/17から導入。各PCに常駐スクリプトが入っていれば自動記録されます。
👤

マイページ

自分のプロフィール・アバター・ニックネーム・パスワード変更などの個人設定。ヘッダの丸アイコンから入れます。

📱

スマホ版・タブレット版

スマホでアクセスすると自動でモバイル版に切替。タブレット (iPad等) は「タブレット版」ボタンで広い画面用UIに。

PWAインストール: ブラウザの「ホーム画面に追加」で実質アプリ化できます。

🩺 健康・食事

🍱

食事投稿 (みんなの広場)

食事の写真をAIが自動で栄養分析。塩分・カロリー・食物繊維・野菜・タンパク質など9項目をエビデンスと対比表示。アルコール飲料も本数カウントされカロリーに加算されます。

食事投稿への反応は 👍 のみ（マウント防止）。それ以外の投稿は8種類の反応が押せます。
🏥

健康管理室

個人アクションプラン、ヘルスアドバイザーAIへの相談、施策ボード、AI評議会の議論、保健師レビュー、役員決済まで一気通貫の入口です。

血圧・健診ファイル・CoWell個人履歴は 本人以外閲覧不可。管理者・推進メンバーにも見えません。
📊

ヘルスリテラシー5問

帝京大学公衆衛生学研究科 福田研究室監修のCCHL設問。本人が直接答える / 推進メンバーが代理入力する両方の入口があります（90日に1回）。

💬 コミュニケーション

🌳

みんなの広場 (投稿フィード)

食事・相談・雑談・健康Tipsなど自由に投稿。匿名投稿も可（ニックネーム表示）。反応ボタンは8種類（👍いいね / ❤️推し / 😊共感 / 💪応援 / 👏すごい / 💡参考 / 🙏ありがとう / 😢心配）。 8種

「心配」「推し」「共感」が多い投稿は AI評議会の重要シグナルになります。職場の温度感が拾われます。
💬

営業所チャット

所属の営業所グループでDM風にメッセージ。Enter送信、Shift+Enter改行。既読表示・通話・ファイル添付対応。

📋

掲示板

全社向けのお知らせ・経営メッセージ・重要連絡。新着があればホームに赤バッジ。

📢

業務連絡 / 運管ポスト

車両不具合・現場の声・ヒヤリハットなどを写真付きで報告。AIが集約し健康管理室の施策化フローに繋がります。

🚨

事故報告

製品事故・車両事故の報告書を作成。荷主向けBC報告書も含めて一括管理。

緊急時: まず電話・口頭で速報。落ち着いてから報告書を作成してください。
👥

メンバー一覧

全社員をアバター付きで一覧。拠点・所属で絞り込み、名前検索可。匿名性のためニックネームは表示しません。

🎯 サークル活動

🎯

サークル一覧・参加

有志のサークル（趣味・スポーツ等）に参加申請できます。部署を越えた交流の場。NEW

各サークルはリーダー・紹介文・メンバー・直近の予定が確認可。参加方式は「リーダー承認制」または「自由参加」を選べます。

サークル作成: 管理者・推進メンバーが新規作成できます。アイコン・カラーテーマ・募集中ON/OFF を自由に設定可。

🚛 LogiHub・現場系

🚛

LogiHub

配車組成・ガント編集・ルート地図・bc-scan現場端末・商品マスタを束ねた物流専用ハブ。logihub.biz-terrace.org として独立しています。2026-05-13

CoWell home の「🚛 LogiHub を開く」カードから入れます (管理者向け)。
📦

bc-scan 倉庫モニター

バーコード読取で出庫管理・ピッキング・ダメージ報告。座間倉庫で実運用中。誤積防止・荷物撮影・Box日次バックアップ対応。

📝

商品マスタ登録

バーコード読取→商品名入力→写真撮影で商品マスタを増やせます。写真はタップで全画面拡大表示。ピッキング時に作業員の視覚的助けに。

❓ よくある質問

パスワードを忘れました
管理者にパスワードリセットを依頼してください。管理画面から再設定できます。
反応ボタンが小さすぎて押しにくい
2026-05-12 の改修で反応ボタンを大幅に拡大しました。それでも押しにくければ画面右下の「A·A」文字サイズ切替で全体を拡大してください（6段階：S/M/L/XL/2XL/3XL）。
反応ボタンの意味は？
8種類すべて意味があります。👍いいね / ❤️推し / 😊共感 / 💪応援 / 👏すごい / 💡参考 / 🙏ありがとう / 😢心配。「心配」は職場の早期介入シグナルとしてAI評議会で重要視されます。
食事投稿で👍以外が押せない
仕様です。食事投稿はマウント防止のため👍のみに制限しています。
商品マスタ登録から戻るとCoWellトップに飛んでしまう
2026-05-13 の改修で `?from=` クエリ方式に変更しました。LogiHub から開けば LogiHub に戻ります。
iPhone SE で3ボタンが窮屈です
2026-05-13 のスマホレイアウト調整でボタンを小さくしました。「マイページ」は「マイ／ページ」の2行表示に。
未読バッジが消えません
該当ページ（掲示板/業務連絡）を開けば自動で既読扱いになります。それでも消えない場合はブラウザ再読込（F5）を。
サークルへの参加申請はどう取り消しますか？
現状取り消し機能はありません。リーダーに直接メッセージで取り下げを伝えてください（v2で対応予定）。
個人の健康データは誰に見えますか？
血圧・健診ファイル・体調メモは 本人のみ。管理者・推進メンバー・他社員には一切見えません。詳細は プライバシーポリシー をご覧ください。
スマホでも使えますか？
はい。自動でモバイル版に切替わります。ブラウザの「ホーム画面に追加」でアプリ化推奨。
