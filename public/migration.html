🩺 (旧) CoWell → 新 CoWell (2026-04-25〜04-27 統合・リブランド)

これまで別アプリだった健康管理 (旧) CoWell は、新 CoWell の「健康管理室」フロアと各機能に統合されました。過去の食事投稿・歩数・栄養分析・バディー会話などのデータは全件アーカイブされ、参照可能です。
旧 CoWell は今後 CoWell Classic として履歴閲覧専用となります。

🆕 新 CoWell で新しく加わった機能

  • 🏢 仮想オフィス — フロアを移動して同僚と話せる(ロビー・健康管理室・会議室など)
  • 💬 DM・グループチャット — 業務メッセージを集約
  • 🩺 現場の声 → 施策(健康管理室v2) — 推進メンバー POST → AI集約 → 施策候補 → 評議 → 全社投票 → 実行
  • 👣 今日の一歩 (myplan) — 個人健康相談 → AIアクションプラン
  • 📋 社内掲示板 / 📢 告知 / 🚛 業務連絡 (車両不具合・遅延)
  • 🎬 動画ライブラリ / 🎨 アバター / 📜 ログ閲覧

📅 統合の経緯

2026-04-25
CoWell廃止 → CoHub Wellness 統合方針決定
健康管理を独立アプリではなく、業務オフィスと同じ屋根の下で「気づきの機会」として提供する方針へ転換。
2026-04-27
CoHub → CoWell リブランド
統合後の正式名称を CoWell に。旧アプリは「CoWell Classic」として履歴閲覧専用へ。
2026-04-28
CoLink (関東BC Safety Navi) を完全吸収
日報1,464件・事故20件・クレーム60件・改善施策10件を全件移行。kanto-bc 単体の新規入力は終了。
2026-04-29〜現在
健康管理室 v2 / 健診Box経年取得 / ヘルスアドバイザー音声会話
凝集型テーマ→施策パイプライン、Box健診の全年取得+トレンド表示、ヘルスアドバイザーとのDM音声会話を順次追加。
💡 引き続きアプリの操作で困ったときは、サイドメニューの「❓ ヘルプ」または健康管理室の「🩺 ヘルスアドバイザー」へお気軽にどうぞ。
過去のCoWellデータをじっくり振り返りたい場合は、サイドメニュー「📦 Classic履歴」からアーカイブにアクセスできます。
